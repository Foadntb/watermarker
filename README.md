# واترمارک‌گذار (اندروید، Jetpack Compose + Material 3)

اپ ساده‌ای که لوگو و/یا متن واترمارک را روی چند عکس می‌اندازد، جای مناسب هر عکس را خودکار پیدا می‌کند و خروجی را در یک فایل ZIP ذخیره می‌کند.

## اجرا

1. پوشهٔ پروژه را در **Android Studio** (نسخهٔ Ladybug یا جدیدتر) باز کن و صبر کن Gradle sync تمام شود.
2. گوشی یا شبیه‌ساز (API 26 به بالا) را وصل کن و Run بزن.

> فایل `gradle-wrapper.jar` در پروژه نیست. Android Studio خودش Gradle 8.9 را دانلود می‌کند. اگر خواستی wrapper کامل داشته باشی، در ترمینال `gradle wrapper` را یک بار اجرا کن.

برای ساخت APK از ترمینال (بعد از ساخت wrapper): `./gradlew assembleDebug`

## امکانات

- انتخاب چند عکس با Photo Picker (بدون نیاز به هیچ مجوز ذخیره‌سازی)
- واترمارک **لوگو**، **متن** یا **هر دو** با تنظیم اندازه و شفافیت
- پیش‌نمایش زندهٔ اولین عکس
- جای‌گذاری هوشمند، جدا برای هر عکس
- رنگ متن (سفید یا مشکی) خودکار بر اساس روشنایی همان نقطه
- خروجی ZIP با همان فرمت ورودی (PNG بماند PNG، بقیه JPEG با کیفیت ۹۵)، با نام `نام‌اصلی_wm`
- چرخش درست عکس‌ها طبق EXIF، حداکثر ضلع خروجی ۴۰۹۶ پیکسل
- تم Material 3 با Dynamic Color (اندروید ۱۲+) و حالت تاریک

## جای‌گذاری هوشمند چطور کار می‌کند

در `WatermarkEngine.chooseSpot` عکس به ۲۵۶ پیکسل کوچک می‌شود و هشت جای ممکن (چهار گوشه و وسط چهار لبه) سنجیده می‌شود. امتیاز هر جا برابر است با شدت لبه‌ها (میزان جزئیات) به‌علاوهٔ نصف انحراف معیار روشنایی (یکدست‌بودن) و یک سوگیری کوچک به نفع گوشه‌ها، به‌ویژه پایین-راست. جایی که امتیاز کمتری دارد انتخاب می‌شود.
این روش چهره یا سوژه را تشخیص نمی‌دهد و فقط شلوغی تصویر را می‌سنجد. اگر بعداً تشخیص سوژه خواستی، می‌شود ML Kit را به همین تابع اضافه کرد.

## ساختار

```
app/src/main/java/com/watermarker/app/
  MainActivity.kt      تم و نقطهٔ ورود
  MainScreen.kt        رابط Material 3
  MainViewModel.kt     وضعیت، پیش‌نمایش، خروجی
  WatermarkEngine.kt   دیکد، انتخاب جا، رسم واترمارک
  Exporter.kt          ساخت ZIP
```
