# واترمارک‌گذار (اندروید، Jetpack Compose + Material 3)

اپ ساده‌ای که لوگو و/یا متن واترمارک را روی چند عکس می‌اندازد و خروجی را در یک فایل ZIP ذخیره می‌کند.

## امکانات

- انتخاب چند عکس با Photo Picker (بدون نیاز به مجوز ذخیره‌سازی)
- واترمارک **لوگو**، **متن** یا **هر دو** با تنظیم اندازه و شفافیت، با پیش‌نمایش زنده
- **جایگذاری خودکار و هوشمند** برای هر عکس: کم‌شلوغ‌ترین گوشه یا لبه
- **دوری از چهره‌ها** با تشخیص چهرهٔ ML Kit (آفلاین)
- **انتخاب دستی** یکی از ۹ جای عکس
- **حالت تکرار مورب** روی کل عکس برای محافظت بیشتر
- **ذخیرهٔ تنظیمات** و لوگو؛ دفعهٔ بعد همه‌چیز سر جایش است
- رنگ متن (سفید یا مشکی) خودکار بر اساس روشنایی همان نقطه
- خروجی ZIP با همان فرمت ورودی (PNG بماند PNG، بقیه JPEG با کیفیت ۹۵)، با نام `نام‌اصلی_wm`
- چرخش درست عکس‌ها طبق EXIF، حداکثر ضلع خروجی ۴۰۹۶ پیکسل

## طراحی

ظاهر اپ از توکن‌های تم پیش‌فرض [Amplify UI](https://ui.docs.amplify.aws/react/theming/default-theme) (رنگ، گردی گوشه‌ها، اندازهٔ متن) روی Material 3 ساخته شده است. کل تنظیمات در `Theme.kt` است. رنگ‌های حالت تاریک از همان پالت مشتق شده‌اند، چون Amplify در آن صفحه مقدارشان را نداده است. فونت Inter فقط لاتین دارد، پس فونت پیش‌فرض سیستم نگه داشته شده تا متن فارسی درست نمایش داده شود.

## build

- **Android Studio:** پوشه را باز کن، sync را صبر کن و Build ← Build APK را بزن.
- **GitHub Actions:** پروژه را در یک ریپو بگذار. فایل `.github/workflows/build.yml` خودش APK می‌سازد و در بخش Artifacts می‌گذارد.

## جایگذاری هوشمند چطور کار می‌کند

در `WatermarkEngine.autoSpot` هشت جای ممکن (چهار گوشه و وسط چهار لبه) روی نسخهٔ کوچک‌شدهٔ عکس سنجیده می‌شود. امتیاز هر جا = شدت لبه‌ها + نصف انحراف معیار روشنایی + سوگیری کوچک به نفع گوشه‌ها (پایین-راست اول) + جریمهٔ سنگین برای هم‌پوشانی با چهره‌ها. جایی که امتیاز کمتری دارد انتخاب می‌شود.

## ساختار

```
app/src/main/java/com/watermarker/app/
  MainActivity.kt      تم و نقطهٔ ورود
  MainScreen.kt        رابط Material 3
  MainViewModel.kt     وضعیت، ذخیرهٔ تنظیمات، پیش‌نمایش، خروجی
  WatermarkEngine.kt   دیکد، انتخاب جا، رسم واترمارک
  FaceFinder.kt        تشخیص چهره با ML Kit
  Exporter.kt          ساخت ZIP
```
